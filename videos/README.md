# Videos de interpretaciones

La ventana **Interpretaciones** muestra qué carpeta usa cada paquete. Coloca allí un archivo como `interpretacion.mp4` o `ensayo_01.mp4`. Usa minúsculas, números y guion bajo. Ejecuta `python -m scripts.indexar_videos` desde la raíz para regenerar el catálogo estático. Después publica el MP4 y el índice actualizado.

Las carpetas están disponibles para grabaciones de los intérpretes.
