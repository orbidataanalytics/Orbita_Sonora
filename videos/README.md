# Videos de interpretaciones

1. Elige la imagen del disco. Debajo de GOES aparece el destino del MP4 relativo al repositorio.
2. Copia la grabación a ese destino. Usa `interpretacion.mp4` para que se detecte automáticamente. Para probar una grabación local, usa **Abrir MP4**.
3. Para añadir varias grabaciones, usa nombres como `ensayo_01.mp4`. Ejecuta `python -m scripts.indexar_videos` desde la raíz y sube también `videos/catalogo.json`.
